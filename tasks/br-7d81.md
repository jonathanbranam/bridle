Builds on br-1ac1 (task done --branch). Do: (1) in the daemon, bridle task done <id> --commit <sha> --branch <branch> removes every agent whose worktree is on that branch (stopping any still running), removes the worktree, and deletes the branch even though a squash-merged branch is not an ancestor (see the sq4m task br-0b22 for --delete-branch handling; reuse it), then records what it removed in the task's thread; a failure to remove one thing is recorded and does not fail the done.
