Goal: agents and their builds get no GUI responsible app, so Gatekeeper's Verifying panel stops stealing keystrokes. The advisor's evidence (docs/questions/open/gatekeeper-verify-dialog-steals-focus-qr8z.md, read it; spike mnzh docs/spikes/open/detached-daemon-and-its-terminal-mnzh.md and docs/design/agent-host/daemon.md cover daemon lifecycle): a process started by launchd shows no window, one under iTerm or tmux does; ad-hoc signing and Developer Tools do not help. Do the smallest thing: bridle launchd install [--project <name>] writes a per-project LaunchAgent plist (~/Library/LaunchAgents/, label like dev.bridle.<project>, ProgramArguments the absolute path of the running bridle binary plus serve and the project's working directory and config, WorkingDirectory the project clone, RunAtLoad, KeepAlive false or crash-only so a deliberate stop stays stopped, stdout and stderr to the project's .bridle log dir, EnvironmentVariables carrying PATH and HOME so claude and git are found), refuses to overwrite without --force, and prints, but never runs, the launchctl bootout/bootstrap commands. bridle launchd uninstall removes the plist and prints the bootout command. Check how the daemon is started today (bridle serve and any autostart, daemon.md) so the plist matches and the daemon still writes its discovery entry and tokens the same way; macOS only, a clear error elsewhere. Then write docs/context/launchd-restart-plan.md (or a section in daemon.md): the exact ordered steps for the human to move each running daemon (bridle, meta-notes, track-web) from tmux to launchd with the least interruption of running agents (what a daemon restart does to running agents, resume behaviour after restart, budget hold), how to verify the window is gone (log stream filter on CoreServicesUIAgent from the ticket), and how to roll back. HARD RULE: the worker must not run launchctl, restart, stop or start any daemon, or install a plist into the real ~/Library; tests write to a temp dir. Acceptance: just check passes; tests for plist content (plutil -lint on macOS if available), refuse-overwrite, uninstall; the restart plan is in the task note for the human. Model: Sonnet. Out of scope: Linux systemd, sharing target/ or node_modules across worktrees (b7cz), autostart of all projects at login, making the daemon detach itself.
