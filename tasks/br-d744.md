Goal: the pre-push marker check added by br-e7f4 in workflow/base/roles/manager.md uses git diff-index --check HEAD after the merge commit; that compares HEAD to the worktree, so it cannot see committed markers. Do: replace it with git grep -nE '^(<<<<<<<|=======|>>>>>>>)' HEAD (run after the merge, before pushing; refuse to push on any match), and say so in the step. Note ======= alone can appear in real markdown (setext headings); if the step would false-positive on this repo's docs, restrict to the <<<<<<< and >>>>>>> lines, followed by a space. Acceptance: just check passes. Model: Haiku. Out of scope: anything else in the manager role.
