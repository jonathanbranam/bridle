Follow-up to fpde (ticket status at 65b7b20; build task br-7b79 landed). crates/bridle-daemon/src/supervisor.rs agent_path() (~line 2950) still calls std::env::current_exe(); on Linux after the binary is replaced that yields "<path> (deleted)", so its parent dir is wrong for the agents' PATH. Switch it to crate::exe_path() (lib.rs:219; it resolves once and strips the suffix), keeping the same fallbacks (no parent -> inherited PATH only; empty inherited PATH -> just the dir). Add a unit test: agent_path() starts with the directory of crate::exe_path() and ends with the inherited PATH (mind that tests share process env; set nothing global, or compare against the current PATH read in the test). Optionally factor the pure join into a small fn taking (Option<dir>, inherited) so the three fallbacks are testable without touching env.
Acceptance: just check passes. CHANGELOG line. Model: Haiku. Out of scope: anything else; any other call site (grep shows this is the last current_exe() in bridle-daemon/src outside lib.rs exe_path itself; if you find another, list it in your report rather than changing it). May land normally.
