Read docs/design/human-web-ui.md sections 3 and 5 first. Goal: username + password login for the gateway: argon2 hash in the machine config (gateway section; add a small way to produce the hash, e.g. 'bridle gateway hash-password'), POST /api/v1/login and /logout, an HttpOnly SameSite=Strict session cookie (random id, server-side in-memory sessions with expiry is fine), and every other /api/v1 route except health refuses without a valid session. No login configured = the gateway refuses to serve beyond health (safe default). Constant-time-ish compare via the argon2 verify; no password in logs. Tests: no cookie refused, wrong password refused, right password sets a cookie with the right flags, logout invalidates. Acceptance: just check passes. Model: Sonnet. Migration: none (new optional machine config). Out of scope: HTTPS, rate-limiting beyond a simple delay on failure, multi-user. Depends on gateway 1.
