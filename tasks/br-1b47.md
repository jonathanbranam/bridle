Sleep is held off only by Claude Code's own short 'caffeinate -i -t 300' calls while a session is working (pmset: sleep 1, i.e. one minute). If every session goes idle, the laptop can sleep and the wake loop, daemons' CI polling and Remote Control stop. Before you go: leave it on power, and run 'sudo pmset -c sleep 0' (never sleep on power; the display can still sleep). Check with 'pmset -g | grep " sleep"'. Undo when back: 'sudo pmset -c sleep 1' (or your old value). FileVault is on, so a reboot or power cut stops at the unlock screen; nothing brings that back remotely.
