Bug: `bridle sync` writes an empty .claude/settings.json into a project on every run. data-contracts removed that file on purpose; sync must not create it.

Fix in crates/bridle-daemon/src/sync.rs `sync_hooks` (~line 475): when the settings file doesn't exist and there are no hooks to add, write nothing (and don't create .claude/ just for this or the hooks sidecar state file). If the file exists, behaviour is unchanged (test 'no_hooks_in_any_layer_leaves_settings_json_untouched' stays green). Check whether sync creates other empty files when its input is empty (CLAUDE.md managed block, skills, agents): fix only if trivial, otherwise report in the task thread.

Acceptance: `just check` passes; tests: no settings.json and no hooks -> stays absent; with hooks -> created as before. Fix docs/design/workflow-layers.md if it says otherwise. Model: Haiku. Out of scope: anything else in sync.
