Goal: parse goals (docs/design/goals-tier.md) in the bridle-spec crate and add `bridle goals list` (local, no daemon; --root DIR default design/goals; --json).

Format: a goal is a heading '## Title {#g-NN}'; the next non-blank line is 'firmness: X · priority: Y · stance: Z' (stance optional; defaults from priority: now->build, next->keep-open, later/someday->unaddressed); body follows. stance unaddressed needs a '**Why unaddressed:**' line, else a warning diagnostic. Values must be in the sets in the doc table; an unknown value is an error diagnostic 'file:line:col: message', same Diagnostic type as the spec parser.

Do: new crates/bridle-spec/src/goals.rs (export from lib.rs; reuse Diagnostic and the {#id} handling from parse.rs/ids.rs; g- ids are hand-written, not assigned). `bridle goals list [--priority P] [--stance S]` prints id, firmness, priority, stance, title; exit 1 on parse errors. Update docs/design/goals-tier.md (built section) and cli.md.

Acceptance: `just check` passes; unit tests for defaults, bad values, missing why, plus a fixture-driven CLI test. Model: Sonnet.

Out of scope: `bridle goals propose`, 'serves:' link validation, goal-change gating, hooks. Touches lib.rs and cli.rs like the other P3 parser tasks: run after the spec-import task merges, not in parallel.
