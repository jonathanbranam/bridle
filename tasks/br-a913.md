Goal: the listing from gateway 3 omits to-dos and task questions that were withdrawn/retracted; the daemon's record keeps them (the gateway never deletes). Tests: a withdrawn to-do and a withdrawn question don't list; the daemon's record still has them. If a retracted question state does not exist on tasks, say so in the task summary and hide only what exists; do not add daemon schema. Acceptance: just check passes. Model: Sonnet. Migration: none. Out of scope: message questions to the human, the inbox. Depends on gateway 3.
