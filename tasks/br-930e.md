Goal (docs/design/worktrees-and-ports.md): a project can say where task worktrees live. Config (crates/bridle-daemon/src/config.rs, .bridle/config.toml): `[worktree] layout = "default"|"root"`, `root = "/path/wt/{task}"` with placeholders {task} (task id if the agent has a claimed task, else agent name), {agent}, {project}. 'default' is today's behaviour (unchanged; must stay the default and byte-identical). Note the existing [worktrees] (plural: setup, copy, warm_target) table: keep it, and document how the two relate (or accept layout/root inside [worktrees] instead if that avoids a confusing pair; choose one, explain in the thread, and update docs/design/worktrees-and-ports.md and agent-host/roles-and-config.md). Worktree creation in crates/bridle-daemon/src/worktree.rs uses the resolved path; `bridle rm` and cleanup (k3wp) must still find and remove it; the containment check that the path is inside the workspace must be relaxed only for an explicit root and validated (absolute, not inside the clone).

Acceptance: just check passes; tests: default unchanged, root with placeholders creates the worktree there, rm removes it, invalid root refused at config load. Model: Sonnet. Out of scope: paired layout (next task).
