Goal (docs/design/impact-and-conflicts.md, conflict protocol step 4, simplest form): when a task lands on the integration branch (`bridle task done <id> --commit <sha>`, crates/bridle-daemon/src/tasks.rs done_task), the daemon sends a message from bridle to every running agent that holds a claimed task or has a worktree branch other than the landed one: 'main moved: task <id> (<title>) landed at <sha>; files changed: <up to 15 paths, then +N more>. Rebase or merge main into your branch when at a safe point, before your next commit.' One message per agent per landing, coalesced if several land within a minute. Not sent to the orchestrator/PM/human or to the agent whose task landed. Get the changed files from git in the project repo (diff-tree of the commit); if git fails, send without the file list.

Files: crates/bridle-daemon (tasks.rs, server.rs/supervisor.rs for message delivery as the wake-manager work br-3bb4 did), docs/design/coordination.md or roles-and-config (whichever documents daemon messages). Acceptance: just check passes; tests with fake agents: two workers, one lands -> other gets exactly one message, the lander none. Model: Sonnet. Out of scope: impact overlap filtering (a later task refines it), auto-rebasing.
