Ticket: docs/questions/open/task-talk-on-the-thread-n8tj.md. Do: (1) bridle send <agent> --task <id> [text or --file] writes the full text as a note on the task's thread and sends the recipient a short message that names the task and points at it ('<id>: note added', with the first line), (2) equivalent bridle task note <id> --notify <agent> (share one implementation; if that is more than a flag, ship only --task, the ticket allows either), (3) a message sent with --task is linked to it and shows in bridle task show <id>'s thread, (4) update the role prompts and skills for manager, worker and product manager under workflow/base/ to use it for briefs, done reports and review findings, and docs/design/cli.md and the messages and API docs.
