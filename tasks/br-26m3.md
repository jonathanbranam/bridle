When the gateway (or a daemon's Tailscale port) stops answering from other machines after bridle is rebuilt, but still answers on dalek itself: macOS's firewall permission for bridle no longer matches the new ad-hoc signature. Re-register the binary on dalek (works over SSH; asks only for the sudo password):

    sudo /usr/libexec/ApplicationFirewall/socketfilterfw --remove /Users/jbranam/.cargo/bin/bridle
    sudo /usr/libexec/ApplicationFirewall/socketfilterfw --add /Users/jbranam/.cargo/bin/bridle
    sudo /usr/libexec/ApplicationFirewall/socketfilterfw --unblockapp /Users/jbranam/.cargo/bin/bridle

Then reload the page; restart `bridle gateway` if it still hangs. Fixed it on 2026-10-04. Close this to-do once br-p88z (stable local signing certificate) has landed, since rebuilds will keep the permission after that.
