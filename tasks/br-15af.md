FileVault is on, so any reboot stops at the disk-unlock screen: no network, Tailscale, SSH or Remote Control until you type the password at the keyboard. An overnight update would end the week's work.
System Settings > General > Software Update > Automatic Updates: turn off 'Install macOS updates' (and security responses, if you want no restarts at all). Turn it back on when you're back.
Finish with `bridle task done <this task>`.
