Goal: workers must not hand off with a red or unchecked HEAD. Twice a worker skipped the full check after its last commit and main went red on fmt. Make it mechanical. Build on the Stop hook: crates/bridle/src/stop_check.rs, wiring in crates/bridle/src/commands.rs, the commands.check_worker binding (workflow/base/skills/worker/SKILL.md and pack config), docs/design/coordination.md, docs/design/cli.md (stop-check). Change: when the worker looks finished (clean tree, commits ahead of integration branch, summary written), the Stop hook confirms the project check_worker command passed at the current HEAD. Simplest design: the hook runs check_worker itself when no pass is recorded for HEAD, records HEAD sha on success (a file in the worktree git dir, never committed), and blocks with the tail of the failing output otherwise; a later stop at the same HEAD skips the rerun. Mind the hook timeout in the Claude Code settings where the hook is registered (raise it if needed); never block on bridle own errors (existing rule); if no check_worker is bound, allow. If running inside the hook is impractical, block until the worker runs a check-done wrapper; pick the simpler and say why in the summary. Acceptance: just check passes; unit tests for pass-recorded (allow), no record (runs check), failing check (block with output tail), no binding (allow). Model: Sonnet. Out of scope: the no-report handoff task (same files, run this one second).
