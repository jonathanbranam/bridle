## What happened

The human, verbatim (2026-09-28, answering sqt6, the short alias):

> sqt6 - no short alias; I want to finish the first rounds of getting it working, then I
> actually was planning to come up with a new, unique name for the entire project. Bridle
> was picked quickly as a pun on harness. Its a fine name, but not very punchy. Add a
> research task for an agent to search the web for existing agentic harnesses and
> catalogue their names so we can avoid overlap. Yegge has Gas Town and Wheelhouse; I'm
> sure there are more.

## Why it matters

The name is chosen once the first rounds work. Picking one that collides with an
existing agent harness, orchestrator or CLI (the way `br` collided with beads_rust)
costs a rename later.

## Notes

The research task: search the web and catalogue existing agentic harnesses,
orchestrators and multi-agent coding tools by name (name, what it is, link, and
the CLI command if it has one), so candidate names can be checked against it.
Record the catalogue in `docs/context/`. Choosing the name is the human's; this
task only gathers the names to avoid.
