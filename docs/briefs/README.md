# Product briefs

Short, plain-language briefs of how each part of bridle works **today**, for the human
deciding what to adopt. Each marks every claim **built**, **partly built** or **planned**,
checked against the code and `CHANGELOG.md`, not the design docs (which can run ahead).
"Built" means in the code, not in use: since 2026-10-03 each brief's status line also says what
is built but not wired in (nothing in the normal flow invokes it;
[[the-workflow-doesn-t-reach-agents-resolved-rules-hooks-and-o-34bw|34bw]]).
