# Orchestrator state

Retired (ct8m step 5, 2026-09-29). The orchestrator's current state is the newest handover note
in bridle: `bridle prime orchestrator` prints it with the role and the startup steps, and
`bridle handover list` / `show <id>` read the history. Live state (agents, queue, CI) comes
from bridle itself. Past sessions' notes and decisions: `orchestrator-history.md`.
